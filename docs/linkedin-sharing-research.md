# Referência de compartilhamento no LinkedIn

## Compartilhamento implementado

Os botões de compartilhamento abrem o fluxo público do LinkedIn para publicar um link de certificação ou de formação. A mensagem de conquista é copiada para a área de transferência durante o clique, para que o aluno possa inseri-la no post antes da publicação.

## Observações verificadas

- O compartilhamento programático de uma publicação em nome de um membro exige autenticação OAuth e a permissão `w_member_social`.
- A documentação do LinkedIn descreve o compartilhamento de URL/artigo usando a API UGC para integrações autenticadas.
- A ajuda do LinkedIn recomenda metadados Open Graph, incluindo `og:title`, `og:image`, `og:description` e `og:url`, para prévias de links compartilhados.
